Dashboard Widgets in HTML and JavaScript

Dashboards need more than bars and lines. These ten widgets cover the pieces people ask for most: a gauge for a score, rings for daily goals, KPI cards with trend lines, a year of activity, a project plan, a profit breakdown, a word cloud and more. Each one is a single HTML file with no library, ready to drop into your own dashboard.
